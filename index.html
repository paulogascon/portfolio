Motion · AI automation

            
AI short-form video pipeline

            

                
Problem
Short-form video takes many manual passes: visuals, captions, motion type and a final audio level that sounds right on every platform. Doing each pass by hand for every reel is slow and inconsistent.

                
Process
I built an end-to-end workflow that combines AI scene generation, Whisper auto-captions and a kinetic typography layer, then masters the result with FFmpeg to the broadcast-style −14 LUFS loudness target used by social platforms.

                
Result
A repeatable pipeline I've used for motion reels and the CICT Wildlife Month 2026 advocacy reel. Every export comes out captioned and at a consistent loudness.

Frontend · Canvas physics

            
This portfolio

            

                
Problem
A portfolio has to load fast on mobile data, read well in dark and light mode, and still show some personality in the first few seconds.

                
Process
Pure static HTML, CSS and JavaScript on GitHub Pages, with no framework or build step. The hanging ID card runs on a custom Verlet spring-physics simulation drawn to canvas, with mouse, touch and keyboard control and a lighter mode for low-end Android phones. Behind it, one particle system written in raw WebGL shaders (no library) morphs from a globe into a wave and a grid as you scroll, reacts to the cursor, touch and phone tilt, and adapts its quality to hold 60fps. The "Ask Paulo's AI" assistant answers from this site's own content, entirely in the browser.

                
Result
A responsive, accessible site with a skip link, visible focus states, reduced-motion support, lazy-loaded reels that play only while on screen, and the inquiry builder you can try below.
